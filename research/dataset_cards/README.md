# Dataset cards

لكل release فعلي أنشئ بطاقة مستقلة تتضمن:

- المصدر الرسمي والرابط وتاريخ المراجعة.
- release/track/version وSHA-256 لكل artifact.
- شروط الوصول والترخيص وإذن الاستخدام التجاري/البحثي، أو `unknown` إذا لم يتحقق.
- الحقول المتاحة فعليًا بعد فحص annotations.
- سياسة الخصوصية والاحتفاظ والـredaction.
- split task-specific ونتيجة فحص التسرب.
- قيود التغطية والـdomain shift.

لا توجد بطاقات release فعلية في Phase 02 bootstrap لأن شروط البيانات من Phase 01 لم تُثبت بعد.
