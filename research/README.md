# YemenVision MTMC — Phase 01 Research Package

## النطاق
هذه الحزمة تؤسس البحث العلمي والهندسي لمنصة تحليل مركبات متعددة الكاميرات في مواقع مصرح بها. لا تتضمن تدريبًا أو تنزيلًا للبيانات أو ادعاءً بدقة محققة على بيانات اليمن.

## الحالة عند البدء
- مساحة العمل كانت فارغة عند بدء المرحلة.
- لم توجد نماذج أو بيانات أو نتائج سابقة محلية.
- لم يُفترض وجود GPU أو إصدار CUDA.

## مخرجات المرحلة
- `RESEARCH_REVIEW.md`: مراجعة منظمة للمحاور العلمية ومصادرها.
- `DATASET_CATALOG.md`: كتالوج بيانات مع فصل المهام والتراخيص وحدود التحقق.
- `MODEL_BENCHMARK.md`: مقارنة عائلات النماذج وخطة قياس محلية.
- `SYSTEM_ARCHITECTURE.md`: المعمارية الأولية وحدود المكونات والواجهات.
- `EXPERIMENTAL_ROADMAP.md`: بوابات وتجارب قابلة للتنفيذ.
- `RESEARCH_GAPS.md`: الفجوات والأسئلة البحثية غير المحسومة.
- `RISK_REGISTER.md`: سجل المخاطر والضوابط.
- `REFERENCES.bib`: مراجع DOI/arXiv/المصادر الرسمية.
- `tools/environment_probe.py`: فحص موارد البيئة دون افتراض GPU.
- `tests/test_phase01_artifacts.py`: اختبارات وجود الملفات وروابط المراجع الأساسية.
- `reports/PHASE_01_ACCEPTANCE_REPORT.md`: تقرير قبول المرحلة.

## سياسة الدليل
كل نتيجة منشورة في الوثائق منسوبة إلى مصدرها، وموسومة بأنها `published` وليست نتيجة YemenVision. أرقام البيانات أو الشروط التي لم يمكن تأكيدها مباشرة من مصدر رسمي في هذه الجلسة موسومة `verify-before-use`.

## التشغيل
```powershell
python tools/environment_probe.py --output reports/environment_probe.json
python -m unittest discover -s tests -v
```

الأمر أعلاه لم يُنفذ تلقائيًا في وقت إنشاء الحزمة؛ يجب تشغيله في البيئة المستهدفة وتسجيل مخرجاته.

## قرار الانتقال
راجع تقرير `reports/PHASE_01_ACCEPTANCE_REPORT.md`. القرار الموصى به: الانتقال المشروط إلى هندسة البيانات بعد تثبيت شروط تراخيص البيانات وإنشاء بروتوكول جمع محلي مصرح به، مع إبقاء نتائج ReID وMTMC التجريبية في بوابة بحث منفصلة.
