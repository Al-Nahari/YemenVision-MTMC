# Notebooks

تم توفير دفاتر Jupyter الأربعة بصيغة `.ipynb` القياسية المتوافقة مع VS Code، مع ملفات `.xml` موازية تمثل نفس الخلايا بصيغة XML المطلوبة للمراجعة/التوليد.

- `01_dataset_inventory`
- `02_data_quality_audit`
- `03_annotation_visualization`
- `04_dataset_statistics`

كل الدفاتر تشرح بالعربية، وتستخدم أسماء Python بالإنجليزية، ولا تفتح raw data أو تعرض لوحات/وجوهًا تلقائيًا. لم تُنفذ الدفاتر لأن لا توجد dataset فعلية أو fixture annotations في هذه المرحلة.
